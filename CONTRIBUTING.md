# Как дорабатывать roomwalk

*[гайд по-русски](README.ru.md) · [English README](README.md)*

Плагин почти целиком состоит из прозы. Код здесь — семь маленьких утилит на Python и
один движок скролла; всё остальное — два `SKILL.md`, которые читает Claude и по которым
он действует. Поэтому «доработать» тут чаще означает **переписать инструкцию**, а не
поправить функцию.

---

## Что где лежит

```
.claude-plugin/marketplace.json     витрина: где искать плагины в этом репозитории
plugins/roomwalk/
  .claude-plugin/plugin.json        имя, версия, автор, ключевые слова
  skills/roomwalk/
    SKILL.md                        конвейер прохода: 11 шагов, правила, режимы отказа
    tools/extract_frames.py      видео → нумерованные кадры + manifest.json (imageio-ffmpeg)
    tools/measure_seams.py       насколько виден каждый стык, в числах
    tools/measure_flicker.py     покадровое дрожание яркости и расстояние по шву петли
    tools/blend_seam.py          смягчить слабый стык, не тратя кредиты
    tools/preview_hero.py        собрать кадр с градиентами и подписью в PNG
    tools/brightness_curve.py    график дрейфа экспозиции по кадрам и сегментам
    tools/stabilise_exposure.py  привести все кадры к общей медиане
    tools/_frames.py             общее: чтение кадров и арифметика яркости
    tools/*.swift                исходные версии только под macOS, оставлены для истории
    tools/connect_higgsfield.py     вход в Higgsfield в обход бага RFC 9207
    web/scroll_frames.js            движок скролла на канвасе с таймлайном ритма
  skills/exploded/
    SKILL.md                        один предмет на чёрном, один дубль, без склеек
  commands/
    connect.md  start.md  walk.md  explode.md
```

Внутри скиллов на инструменты ссылаются через `${CLAUDE_PLUGIN_ROOT}` — не пишите
абсолютных путей, они сломаются у всех, кроме вас.

## Локальная разработка

Поставьте витрину не с GitHub, а с диска — тогда правки видны сразу, без коммита и пуша:

```bash
claude plugin marketplace add ~/path/to/roomwalk
```

```bash
claude plugin install roomwalk@roomwalk
```

Проверить, что скилл действительно подхватился и как он себя описывает:

```bash
claude plugin list
```

Правки в `SKILL.md` подхватываются при следующем запуске сессии — перезапустите Claude Code
после изменения. Правки в `.py` подхватываются сразу, шага сборки нет вовсе.

Когда закончите — снимите локальную витрину, чтобы не жить на двух копиях сразу:

```bash
claude plugin marketplace remove roomwalk
```

## Как менять скилл, чтобы не стало хуже

`SKILL.md` — не документация, а инструкция исполнителю. Разница практическая:

**Пишите числа, а не прилагательные.** «Плавный скролл» ничего не задаёт. «9–10 пикселей
на кадр» задаёт. Почти все правила в этих файлах появились как замеры на живой сборке —
1,07–1,86× против 6,3× на шве, дрейф +15…−37, 30 % скролла на остановки. Если добавляете
правило, добавьте и число, которым оно проверяется.

**Пишите режим отказа, а не только рецепт.** Самая полезная часть каждого шага — «вот
что сломается, если сделать наоборот, и вот как это выглядит на экране». Правило без
симптома исполнитель тихо обойдёт.

**Проверяйте на живом заказе, а не на себе.** Единственный способ понять, что правка
работает, — прогнать полный конвейер на настоящем сайте и посмотреть **на канвас**, а не
на логи. Половина ошибок в истории этого репозитория выглядела в консоли безупречно.

**Раздел про честность не смягчается.** Запреты на лица, «до и после», сгенерированную
еду, чужие бренды и выдуманные характеристики — не стилистика. Это то, что отделяет
инструмент от генератора вводящей в заблуждение рекламы, и снимать их нельзя, даже если
конкретный клиент просит.

## Выпуск версии

1. Поднимите `version` в `plugins/roomwalk/.claude-plugin/plugin.json` — семвер: патч на
   исправление формулировки, минор на новое поведение или новый скилл.
2. Обновите таблицы и числа в `README.md` и `ГАЙД.md`, если поведение изменилось. Оба
   файла описывают одно и то же — расхождение между ними хуже, чем устаревшее место
   в одном.
3. Один коммит с заголовком вида `0.6.0 — что изменилось одной фразой`.
4. `git push`. Установленные копии подтянут новое на `claude plugin update roomwalk`.

## Если хотите добавить свой герой

Третий скилл делается копированием `skills/exploded/` — он самый короткий и лучше всего
показывает форму: чем герой отличается от соседей, что нужно до старта, конвейер по
шагам, чем проверяется результат, где проходит граница честности.

Положите его в `skills/<имя>/SKILL.md`, добавьте `commands/<имя>.md` в одну строку
(«загрузи скилл `<имя>` и следуй ему»), впишите строку в таблицу выбора в обоих README.
Инструменты не дублируйте — ссылайтесь на `skills/roomwalk/tools/`, как это делает
`exploded`.

Описание в шапке скилла (`description:`) — единственное, по чему Claude решает, брать его
или нет. Перечисляйте там формулировки, которыми человек попросит: «лендинг товара»,
«разбирается на скролле», «hero как у Apple». Красивое обобщённое описание означает, что
скилл не подхватится никогда.

## Порядок работы с репозиторием

Есть доступ на запись — работайте ветками и присылайте pull request: `main` должен
оставаться тем, что можно ставить не глядя.

Доступа нет — форкайте, правьте у себя, присылайте PR оттуда. Ставится форк точно так же:

```bash
claude plugin marketplace add ваш-логин/roomwalk
```

В PR опишите, **на чём проверяли**: какой сайт, сколько сегментов, что показали замеры до
и после. Правка в скилле без прогона — это гипотеза, а не улучшение.
